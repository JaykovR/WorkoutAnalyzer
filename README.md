# Workout Progress Analyzer

This program analyzes a dataset (.csv) of a person throughout a specific exercise.

The .csv file should contain Date, Weight and Reps. The sets included should be your **WORKING SETS**.

After excecuting the program you will get in return your average lifting weight *(for that exercise)*, your average number of reps, and your estimated 1RM *(One Rep Max)*.
You will also get a graph showing you your progress of your 1RM per workout.

This is an MVP for this small program.
*I plan to introduce an interface later on*

Libraries used: Pandas | NumPy | Matplotlib | Tkinter
